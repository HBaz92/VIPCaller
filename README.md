# VIP Caller

**VIP Caller** is a smart Android utility app that helps users recognize important incoming calls by playing the caller’s custom contact ringtone.

The app works without root and uses Android’s existing contact ringtone configuration.

---

## Overview

VIP Caller detects incoming phone calls and checks whether the caller has a custom ringtone assigned in the Android Contacts app.

If a custom ringtone exists, VIP Caller plays that same ringtone automatically and stops it when the call is answered, rejected, or ended.

---

## Features

- Detects incoming calls
- Reads custom contact ringtones from Android Contacts
- Plays the assigned ringtone for important callers
- Stops the ringtone automatically when answering or ending the call
- Works without root access
- Modern Material 3 user interface
- Arabic and English tabs
- Samsung / One UI friendly design

---

## How to Use

1. Install the app.
2. Open VIP Caller once.
3. Allow the required permissions.
4. Assign custom ringtones to important contacts from the Android Contacts app.
5. VIP Caller will work automatically in the background.

No additional setup is required after granting permissions.

---

## Required Permissions

VIP Caller requires the following permissions:

- Phone state access  
  Used to detect incoming calls.

- Contacts access  
  Used to read the custom ringtone assigned to a contact.

- Call log / phone access  
  Used to improve caller detection behavior on Android devices.

- Do Not Disturb access  
  Optional, used to improve sound behavior in silent or DND scenarios.

The app does not upload contacts, call data, or personal information.

---

## Compatibility

- Minimum Android version: Android 7.0 Nougat
- Minimum SDK: API 24
- Tested primarily on Samsung / One UI devices

Behavior may vary depending on manufacturer battery restrictions, sound mode, and Android version.
